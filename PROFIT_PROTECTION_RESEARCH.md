# KT13 – Profit Protection
Only research-v3, daily SMA50/SMA200. S0/S2/S5 × P0–P6. P0 must match KT03 state, ledger, equity.
Profit activation uses net hypothetical liquidation at each completed close, using raw entry open and original fee/tax/slippage on both sides. Net factor = (1-slip)*(1-sellfee-tax)/(entry_open*(1+slip)*(1+buyfee)). Lock L% means quote threshold (1+L/100)/factor. Threshold never decreases during position. No intraday high or future prices used. P6 is an additional close-1.5 ATR ratchet once net close peak reaches 5%, eligible immediately; existing 2 ATR trailing unchanged. Priority initial, protection, original trailing (age 3), score. Re-entry requires original fresh confirmation; sell next open and gap may violate floor. No fabricated final exit.
P0 matched separately for each base; all variants also compared with S0P0. Matched winners/losses by buy date, unmatched not inferred. Peak close minus realized return can be negative if exit opens above peak. All metrics single stock, not portfolio. Retrospective six-month slices not OOS. No changes to original strategies, KT03, TCBS, app.py, frozen baseline.
Default quick 42 cases (2×3×7), full 252 (12×3×7). Export summary, ledger, windows and errors.
